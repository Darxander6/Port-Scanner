# Port-Scanner
It scans ports with pyhton.It uses the frame work scappy.It checks for all broadcsting ports which would be the ones you can interact with and the ones that you would want to do things with.It also marks what certain ports are for like ssh is 22.To use it just go to this link https://port-scanner-with-python.streamlit.app/ or download the .exe and run it on any hardware that has windows or even linux and mac with the wine software, for scanning for ip addresses on a network it requires that you have Npcap .It used multi threaded scanning to make it effcient.It is only CLI with the installed version.<img width="788" height="843" alt="image" src="https://github.com/user-attachments/assets/08636c4a-30dc-4b25-9a0c-a022e0680708" />
